## 🚀 Dự án tiêu biểu

### 🦟 E-Dengue — Hệ thống thông tin và cảnh báo sốt xuất huyết

**WebGIS · Public-health information · Full-stack web application**

Dự án hướng đến việc cung cấp thông tin và cảnh báo về dịch sốt xuất huyết, kết hợp website với bản đồ WebGIS để hỗ trợ theo dõi và trực quan hóa thông tin địa lý.

**Công nghệ liên quan**
- **Backend:** Java 17, Spring Boot
- **Frontend:** React / TypeScript
- **Database:** MongoDB
- **Mapping:** OpenLayers

**Các điểm kỹ thuật nổi bật**
- Tổ chức backend và API phục vụ ứng dụng web.
- Kết hợp dữ liệu với giao diện bản đồ tương tác.
- Hướng đến cách trình bày thông tin trực quan, dễ tiếp cận.
